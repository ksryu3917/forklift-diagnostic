# V8.2 Diagnostic-first priority

## Core release order
1. Symptom reproduction and safety
2. Required subsystem-only redrawn circuit/hydraulic diagram
3. Exact test location and access/location map
4. Loaded/dynamic measurement method
5. Normal-side comparison / isolation / bypass test
6. Confirmation criteria and disassembly gate
7. OEM source evidence
8. Exploded view / physical location reference
9. Part number / serial applicability (reference only)
10. Price / labor (later operational DB)

Part number completeness does **not** determine diagnostic readiness. Actual parts purchasing must be confirmed by chassis/serial through the parts counter/EPC because service replacements and supersessions are common. The Parts Book is primarily used here for physical location, assembly relationship, harness routing group, and exploded views.
