# 지게차 진단 Android FULL v0.1

컴퓨터 없이 GitHub Actions에서 APK를 자동 빌드하도록 만든 Android 네이티브 프로젝트입니다.

## 포함 기능
- 차량 선택
- 기존 64개 증상 DB
- 계통별 / 키워드 증상 검색
- 전·후진 전기계통 실행형 분기 진단
- STEP별 관련 자료 / 점검조건 / 방법 / 판정 / 다음 단계
- OEM 원문은 선택형 근거 보기
- OEM 중요 이미지 94개를 개별 파일로 저장하여 필요한 순간만 로딩
- 매뉴얼 관리 / 검색 / PDF 등록
- 부품·가격 DB
- 정비 이력
- 내 현장 경험
- Android 뒤로가기
- GitHub Actions 자동 APK 빌드

## 현재 완성도
기존 데이터 전체를 버리거나 재분석하지 않았습니다.
64개 증상 전체가 실행형 의사결정 그래프로 완성된 것은 아니며, 검증된 전·후진 전기진단부터 실행형입니다.
미완료 원인은 '정규화 대기'로 표시하며 앱이 임의 검사값/순서를 만들지 않습니다.

## 자동 빌드
프로젝트 파일을 GitHub 저장소 최상위에 올린 뒤 Actions에서 `Build Android APK`가 실행됩니다.
성공하면 Artifacts의 `forklift-diagnostic-apk`를 받아 압축을 풀고 `app-debug.apk`를 설치하면 됩니다.
