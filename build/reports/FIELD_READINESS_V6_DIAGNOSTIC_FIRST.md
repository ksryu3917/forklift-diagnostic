# FIELD READINESS V6 · DIAGNOSTIC FIRST

## 판정 원칙

**품번 완성도는 진단 합격조건이 아니다.** 실제 구매는 차대번호 기준 부품점/EPC에서 최종 확인한다. Parts Book은 위치·조립관계·분해도 확인에 우선 사용한다.

### 앱 우선순위

1. 증상 재현/안전
2. 고장 전용 재작성 회로·유압도
3. 측정/점검 위치
4. 부하·동적 측정
5. 정상측 비교/격리/바이패스
6. 확정조건/분해게이트
7. OEM 근거
8. 분해도/장착 위치
9. 참고 품번
10. 가격/공임

- 논리 시뮬레이션을 실차 고장사례 로그로 계속 교차검증

## UI 변경

- 진단화면에서 품번/Serial 버튼을 상단에서 제거했다.
- **점검 위치 → 재작성도 → 측정점 → 격리/확정**이 먼저 보인다.
- 분해도/부품 위치는 결과 뒤에 참고로 노출한다.
- 엔진 센서창은 **위치/핀/OEM 실제 장착도**를 먼저 보이고 품번은 맨 아래 참고정보로 내렸다.
- 부품 화면도 “분해도/장착 위치 참고”로 바꾸고 Serial 필터는 선택 참고 기능으로 내렸다.
